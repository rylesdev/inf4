## Contenu du projet

Le projet contient les notebooks réalisés pendant les séances de Python du module INF4.

Pour l'instant, on a travaillé sur les bases de Python, NumPy, pandas et la manipulation de données.

## Notebooks

### `01-Python-NumPy.ipynb`

Premier notebook avec les bases de Python et NumPy :

- listes, dictionnaires, conditions, boucles et fonctions
- tableaux NumPy
- slicing et indexation
- masques booléens
- calculs et statistiques avec NumPy
- première utilisation de pandas

### `02-Pandas-Manipulation-S2.ipynb`

Notebook consacré principalement à pandas :

- DataFrame et Series
- sélection de colonnes
- filtres
- `.loc` et `.iloc`
- tri des données
- création de nouvelles colonnes
- statistiques
- `groupby()`
- lecture et export de fichiers CSV

### `03-Data-Cleaning-S3.ipynb`

Notebook de la troisième séance consacré au nettoyage des données.

## Données

Les fichiers CSV utilisés sont dans le dossier `data` :

- `homelessness.csv`
- `sales_subset.csv`
- `temperatures.csv`
